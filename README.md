# Crew Me GitHub Pages site

This is a starter site and **draft** legal text. Before publishing, replace every `[INSERT ...]` placeholder in `terms.html` and `privacy.html`, verify claims against the deployed bot, and review the policies for your jurisdiction. Do not publish an incomplete policy as final.

## Deploy
1. Create a **public** GitHub repository, e.g. `crew-me-site`.
2. Upload `index.html`, `terms.html`, `privacy.html`, and `style.css` to the repository root.
3. In repository **Settings → Pages**, choose **Deploy from a branch**, `main`, `/ (root)`, and Save.
4. Wait for GitHub Pages deployment. Your site will typically be `https://YOUR-USERNAME.github.io/crew-me-site/`.
5. Enter `https://YOUR-USERNAME.github.io/crew-me-site/terms.html` as the Discord Terms of Service URL and `https://YOUR-USERNAME.github.io/crew-me-site/privacy.html` as the Privacy Policy URL, replacing YOUR-USERNAME.
6. Leave Interactions Endpoint URL and Linked Roles Verification URL blank for a Gateway-based discord.py bot without Linked Roles integration.

Do not put your bot token, database, private tickets, or staff records in the public repository.
